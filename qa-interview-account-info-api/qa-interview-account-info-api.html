Your assignment

Design test scenarios for the account lookup endpoint against the parameter table on the right. Use the console below to issue requests and read the simulated responses, then talk the interviewer through your scenarios out loud — the workspace below is there if you want to jot anything down, but writing is optional.

  1. Explore every parameter combination: mandatory-only, mandatory + each optional field, and all four together.
  2. Design scenarios that cover happy-path, negative, and edge cases — as many as you can within the time.
  3. Talk the interviewer through each scenario out loud: the test data, the expected result, and how you'd prioritize it by risk.
  4. Be ready to explain what you'd automate at which layer — unit, API/contract, or UI — and why.

Product context — API spec

GET /account/infoRead-only lookup, no side effects, safe to repeat.
firstName, lastNameMandatory · String · Exact match · supports Thai & English
accountNum, accountTypeOptional · accountNum is a 10-digit number; accountType is one of All, Fixed, Saving, Current
Response shapeEnvelope object with status, count, and a results array. Empty array when nothing matches (404 vs. 200+[] is unconfirmed) — see the sample below.
